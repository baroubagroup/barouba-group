# 🏛️ BAROUBA GROUP SARL — Plateforme Digitale Officielle & Pôle IA d'Élite

> **Agence Digitale de Référence & Pôle IA d'Élite en Afrique de l’Ouest.**  
> Siège Social : Bobo-Dioulasso, Burkina Faso | Bureaux & Déploiements : Ouagadougou & Bobo-Dioulasso | Rayonnement : Espace UEMOA & International.

## 🚀 Présentation de la Plateforme

Plateforme web de haute autorité et d'hyper-conversion conçue pour imposer le leadership de **BAROUBA GROUP SARL** sur l'ensemble de ses pôles stratégiques :

* **Communication Digitale & Community Management :** Gestion intégrale de pages, storytelling de marque et création de contenu d'autorité.
* **Développement Web & Applications Next.js 16 :** Architectures modernes modulaires sans dépendance captive, optimisées pour un affichage en moins de 0.8s sur réseaux 3G/4G au Sahel.
* **Media Buying & Publicité Payante :** Campagnes haute rentabilité sur Meta Ads (Facebook/Instagram) et TikTok Ads avec tracking serveur CAPI anti-déperdition.
* **Tunnels de Vente & Vente WhatsApp :** Écosystèmes de passage en caisse 1-clic connectés directement aux habitudes d'achat ouest-africaines et aux flux Mobile Money.
* **Pôle IA & Automatisation Métier :** Agents virtuels 24/7, intégration de modèles LLM et génération de visuels publicitaires sahéliens photoréalistes.
* **Pôle Académique d'Élite :** 6 programmes de formation professionnelle pratique aux métiers du numérique.

---

## 🏗️ Stack Technologique & Architecture

* **Framework :** [Next.js 16](https://nextjs.org/) (App Router) + React 19 + TypeScript
* **Internationalisation :** `next-intl` (Français / Anglais) avec routage dynamique localisé
* **Design System :** Obsidian Sombre & Or Sahélien avec support bimodal Sombre / Clair (`[data-theme='light']`)
* **Performances Web :** Score Google Lighthouse 95+ sur mobile, streaming SSR et composants modulaires
* **Outils Métier Embarqués :**
  * Générateur de devis interactif multi-services avec calcul budgétaire en FCFA (`/devis`)
  * Assistant IA interactif avec avatar officiel (`/logo-or.svg`)
  * Boutique numérique de templates, outils IA et abonnements sérénité (`/boutique`)
  * Espace de commandement administratif sécurisé (`/admin`) avec télémétrie géographique en temps réel et CRM synchronisé

## ⚡ Démarrage Rapide

```bash
# 1. Cloner le dépôt
git clone https://github.com/baroubagroup/barouba-group.git
cd barouba-group

# 2. Installer les dépendances
npm install

# 3. Lancer le serveur de développement local
npm run dev

# Accéder au site : http://localhost:3000
# Accéder à l'admin : http://localhost:3000/admin (mot de passe : barouba2026)
```

---

## 📦 Scripts Disponibles

* `npm run dev` : Lance le serveur de développement avec Turbopack.
* `npm run build` : Compile la plateforme pour la production.
* `npm run start` : Démarre le serveur de production.
* `npm run lint` : Vérification du code source via ESLint.

---

## ☁️ Déploiement Continu sur Vercel

1. Connectez-vous à votre compte [Vercel](https://vercel.com).
2. Cliquez sur **Add New... > Project** et importez le dépôt `baroubagroup/barouba-group`.
3. Le preset **Next.js** est détecté automatiquement.
4. Cliquez sur **Deploy**. Chaque push sur la branche `main` déclenchera un déploiement automatique.
