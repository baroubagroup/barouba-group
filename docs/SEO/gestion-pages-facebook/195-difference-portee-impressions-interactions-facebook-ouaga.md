## 1. Portée (Reach) vs Impressions : La Grande Distorsion Expliquée Simplement

C'est la confusion numéro un constatée chez 90 % des entrepreneurs au Burkina Faso. Beaucoup pensent que la portée et les impressions sont synonymes. C'est totalement faux !

```
          LA MÉTAPHORE DE L'AVENUE KWAMÉ N'KRUMAH À OUAGA
+---

-+
| LA PORTÉE (REACH) : LE NOMBRE DE PERSONNES PHYSIQUES DIFFÉRENTES        |
| -> C'est le nombre d'êtres humains uniques qui ont vu votre publication|
|    apparaître au moins une fois sur l'écran de leur smartphone.         |
| -> Exemple : 10 000 personnes de Ouagadougou ont croisé votre panneau.  |
+---

-+
| LES IMPRESSIONS : LE NOMBRE TOTAL D'AFFICHAGES À L'ÉCRAN                |
| -> C'est le nombre de fois où le post est apparu au total sur les       |
|    écrans, sachant qu'une même personne peut le voir plusieurs fois !   |
| -> Exemple : Monsieur Sawadogo a vu votre annonce le matin à 8h dans son|
|    lit, puis l'a revue à midi à la pause café, puis le soir à 21h.      |
|    RÉSULTAT : Portée = 1 personne | Impressions = 3 fois !              |
+---

-+
```

### La notion capitale de "Fréquence" (Frequency) :
La fréquence est le rapport mathématique entre les deux grandeurs :
$$\text{Fréquence} = \frac{\text{Impressions}}{\text{Portée}}$$

- Si vos impressions s'élèvent à **60 000** pour une portée de **20 000 personnes** :
  $$\text{Fréquence} = \frac{60\,000}{20\,000} = \mathbf{3{,}0}$$
  *Signification : Chaque habitant ciblé à Ouaga a vu votre publication en moyenne 3 fois.*

```
             QUELLE EST LA BONNE FRÉQUENCE DE DIFFUSION À OUAGA ?
• Fréquence entre 1,2 et 2,0 : IDÉAL POUR LA NOTORIÉTÉ INITIALE
  -> Vous touchez beaucoup de personnes différentes sans les harceler.

• Fréquence entre 3,0 et 5,0 : IDÉAL POUR LA CONVERSION & LE CLOSING
  -> C'est la répétition qui déclenche l'acte d'achat chez le client méfiant !

• Fréquence > 8,0 : DANGER DE SATURATION (FATIGUE PUBLICITAIRE)
  -> Les internautes de Ouaga en ont marre de voir la même photo partout :
     ils commencent à masquer vos publicités par exaspération !
```

## 2. Portée Organique vs Portée Payée (Sponsorisée)

Dans vos rapports d'activité, vous observerez toujours la portée scindée en deux catégories :

```
                  PORTÉE ORGANIQUE vs PORTÉE PAYÉE
[Portée Organique (Gratuite)]
-> Nombre de personnes touchées NATURELLEMENT sans payer un franc à Meta.
-> Dépend de l'amour de l'algorithme, des partages et des commentaires.
-> En 2026 au Burkina Faso : Ne dépasse plus 2 % à 4 % de vos abonnés !
           │
           ▼
[Portée Payée (Sponsorisée / Ads)]
-> Nombre de personnes touchées GRÂCE À VOTRE CARTE BANCAIRE (Meta Ads).
-> Vous achetez de la visibilité garantie auprès des cibles choisies
   (ex : Hommes de 30-55 ans résidant à Ouaga 2000 et Koulouba).
```

Un bon community manager à Ouaga ne se vante pas d'avoir touché 50 000 personnes si l'entreprise a dû injecter 300 000 FCFA de publicité pour y parvenir ! La vraie compétence réside dans l'art de maximiser la **portée organique gratuite** par la qualité du contenu.

## 3. Clics Tout Court vs Clics sur le Lien (Le Piège Classique)

Voici l'astuce la plus vicieuse utilisée par certains prestataires pour gonfler artificiellement leurs résultats de campagne.

Sur Meta Ads, il existe deux métriques de clics totalement distinctes :

| Métrique Affichée | Ce Que l'Internaute a Fait sur son Téléphone | Valeur Commerciale Réelle |
| :--- | :--- | :--- |
| **"Clics (Tous)" (Clicks All)** | L'internaute a cliqué n'importe où : pour agrandir la photo, lire la suite du texte, mettre pause à la vidéo, ou voir les commentaires. | **Faible** (Simple curiosité de passage). |
| **"Clics sur le Lien" (Link Clicks)** | L'internaute a cliqué expressément sur le bouton officiel d'action : **"Envoyer un message WhatsApp"** ou vers votre catalogue ! | **MAXIMALE ET DÉCISIVE !** C'est le seul clic qui amène un client chez vous. |

> **Le conseil d'expert de BAROUBA GROUP :** Exigez formellement de ne regarder QUE les **"Clics sur le lien" (Link Clicks)** dans vos rapports. Si une agence vous annonce 1 500 clics mais que vous découvrez qu'il s'agissait de clics pour agrandir une image et que seulement 12 personnes sont arrivées sur WhatsApp, votre budget a été gaspillé !

## 4. Taux de Clic (CTR) : La Mesure de l'Attractivité de Votre Offre

L'acronyme **CTR (Click-Through Rate ou Taux de Clic)** mesure le pourcentage de personnes qui ont cliqué sur votre annonce après l'avoir vue à l'écran.

```
                     LA FORMULE OFFICIELLE DU CTR
                       Nombre de Clics sur le Lien
             CTR = ---

x 100
                         Nombre d'Impressions
```

### Comment noter le CTR de vos annonces à Ouagadougou ?
- **CTR < 1,0 % : ANNONCE MÉDIOCRE OU HORS SUJET**
  - Votre visuel n'attire pas le regard, ou votre texte est trop long et ennuyeux. Les Ouagalais font défiler leur écran sans même s'arrêter.
- **CTR entre 1,5 % et 2,5 % : NIVEAU STANDARD DU MARCHÉ FASO**
  - Votre annonce fonctionne correctement et génère un flux continu d'acheteurs.
- **CTR > 3,5 % : EXCELLENCE PUBLICITAIRE (CARTON PLEIN !)**
  - Votre visuel est magnétique, votre offre promotionnelle est perçue comme irrésistible. Vos coûts d'acquisition s'effondrent vers le bas !

## 5. Interactions (Engagement) : Quand le Public Réagit

Le terme global **"Interactions" (ou Engagement)** regroupe la somme de toutes les actions actives entreprises par les internautes sur votre publication :

```
             LA PYRAMIDE DE VALEUR DES INTERACTIONS À OUAGA
                      ▲
                     / \     [Niveau 1 : LE MESSAGE WHATSAPP / CLOSING]
                    /   \    -> L'action la plus rémunératrice en FCFA.
                   /─────\
                  /       \   [Niveau 2 : LE PARTAGE PUBLIC]
                 /         \  -> Recommandation directe à ses proches.
                /───────────\
               /             \ [Niveau 3 : LE COMMENTAIRE RÉDIGÉ]
              /               \-> Demande d'information, avis, question.
             /─────────────────\
            /                   \ [Niveau 4 : LA RÉACTION ÉMOTIONNELLE]
           /                     \-> J'adore, Solidaire, Wouah, Rire.
          /───────────────────────\
         /                         \ [Niveau 5 : LE SIMPLE "J'AIME"]
        /                           \-> Clic machinal sans grande attention.
       /─────────────────────────────\
```

## Questions Fréquentes (FAQ)

### Quelle est la différence entre portée et impressions ?
La portée compte le nombre de personnes uniques touchées, tandis que les impressions mesurent le nombre total d'affichages à l'écran.

### Pourquoi surveiller les clics sur le lien plutôt que les clics tous ?
Seul le clic sur le lien mène directement le prospect sur votre WhatsApp ou votre boutique pour finaliser la commande.

### Quel est le CPM moyen sur Meta Ads au Burkina Faso ?
Le coût pour 1 000 impressions au Burkina Faso se situe en moyenne entre 500 et 1 500 FCFA selon la concurrence du secteur.
