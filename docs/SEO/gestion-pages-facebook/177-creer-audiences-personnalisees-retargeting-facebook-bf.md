## 1. Qu'est-ce que le Retargeting et Pourquoi est-il 3 Fois Plus Rentable à Ouaga ?

Le retargeting consiste à diffuser des publicités spécifiques uniquement aux personnes qui ont déjà eu un point de contact préalable avec votre entreprise.

```
       LE PARCOURS D'ACHAT COMPARÉ : PROSPECTION vs RETARGETING
+---

-+
| SCÉNARIO 1 : LA PROSPECTION FROIDE CLASSIQUE                            |
| Annonce diffusée à un inconnu total à Ouaga.                            |
| -> Réaction : Méfiance, doute sur l'authenticité, besoin de réflexion.  |
| -> Taux de conversion moyen : 1 % à 2 %.                                |
| -> Coût par vente : Élevé (ex: 8 000 FCFA).                             |
+---

-+
| SCÉNARIO 2 : LE RETARGETING D'AUDIENCE CHAUDE                           |
| Annonce diffusée à quelqu'un qui a déjà discuté avec vous sur WhatsApp. |
| -> Réaction : Confiance déjà établie, sentiment de familiarité.        |
| -> Taux de conversion moyen : 8 % à 15 % !                              |
| -> Coût par vente : Très bas (ex: 2 000 FCFA).                          |
+---

-+
```

### Le phénomène de la "Mémorisation de Marque" à Ouagadougou :
Lorsqu'un cadre de Ouaga voit votre publicité un lundi, puis revoit une offre spéciale le jeudi avec un témoignage client, puis une démonstration le dimanche, il a l'impression que votre entreprise est partout et qu'elle domine son secteur. Cette répétition ciblée forge une autorité institutionnelle irrésistible.

## 2. Les 4 Sources d'Audiences Personnalisées les Plus Puissantes au Burkina Faso

Dans le Gestionnaire de Publicités Meta, rendez-vous dans l'onglet **"Audiences"** (icône avec trois silhouettes). Cliquez sur **"Créer une audience" > "Audience personnalisée"**. 

Voici les 4 gisements de données locales les plus rentables :

```
       LES 4 SOURCES D'AUDIENCES PERSONNALISÉES SUR META AU FASO
1. LES PERSONNES AYANT ENVOYÉ UN MESSAGE À VOTRE PAGE (Messenger/WhatsApp)
   -> La crème de la crème : ceux qui ont déjà engagé une conversation !
   │
2. LES VISITEURS ET ENGAGÉS DE VOTRE PAGE FACEBOOK ET COMPTE INSTAGRAM
   -> Ceux qui ont aimé, commenté ou enregistré vos publications (365 jours).
   │
3. LES SPECTATEURS DE VOS VIDÉOS ET REELS (Video Views)
   -> Les personnes ayant regardé plus de 50 % ou 75 % d'une vidéo de démo.
   │
4. VOTRE FICHIER CLIENT TÉLÉPHONIQUE (Base de numéros WhatsApp)
   -> Importation directe de vos listes de contacts Orange Money / Wave.
```

## 3. Configuration Pratique : Créer Vos 3 Audiences Clés

Détaillons les étapes pour configurer vos trois premières audiences chaudes.

### Audience N°1 : Les Personnes Ayant Interagi avec Votre Page (Engagement 180 Jours)
1. Choisissez la source : **"Page Facebook"**.
2. Événement : Sélectionnez *"Toutes les personnes ayant interagi avec votre Page"*.
3. Rétention : Indiquez **180 jours** (soit les 6 derniers mois).
4. Nom de l'audience : `AUD-ENGAGEMENT-PAGE-FB-180J`.
5. Cliquez sur **"Créer l'audience"**.

### Audience N°2 : Les Prospects Ayant Envoyé un Message Privé (Le vivier le plus chaud)
1. Choisissez la source : **"Page Facebook"**.
2. Événement : Sélectionnez spécifiquement *"Personnes ayant envoyé un message à votre Page"*.
3. Rétention : Indiquez **90 jours**.
4. Nom de l'audience : `AUD-MESSAGES-RECUS-90J`.

### Audience N°3 : Importation de Votre Fichier Client Téléphonique Burkinabè
Si vous notez les numéros de téléphone de vos clients dans un carnet ou un fichier Excel lors des paiements Orange Money ou des livraisons, vous possédez une mine d'or !
1. Créez un fichier Excel simple avec une colonne unique intitulée `phone`.
2. Inscrivez les numéros au format international avec l'indicatif burkinabè : `+22670XXXXXX`, `+22676XXXXXX`, `+226 74 82 66 66`.
3. Enregistrez le fichier sous format **CSV (séparateur point-virgule ou virgule)**.
4. Dans Meta Ads, choisissez la source : **"Liste de clients"**.
5. Téléversez votre fichier CSV. Meta hache et crypte les données pour faire correspondre les numéros de téléphone avec les profils Facebook réels des acheteurs.
6. En 30 minutes, vous obtenez une audience sur-mesure composée à 100 % de vrais acheteurs burkinabè !
