## 1. La Formule Fondamentale de la Rentabilité Publicitaire au Burkina Faso

Avant d'ouvrir le Gestionnaire de Publicités Meta, vous devez impérativement poser trois chiffres sur une feuille de papier :

```
          LES 3 VARIABLES DU CALCUL DE RENTABILITÉ PUBLICITAIRE
+---

-+
|                                                                         |
| 1. VOTRE MARGE BRUTE UNITAIRE EN FCFA (M)                               |
|    -> Prix de vente TTC - Prix d'achat/fabrication - Coût de livraison.  |
|    -> Exemple : Vous vendez une paire de chaussures 25 000 FCFA.         |
|       Elle vous a coûté 13 000 FCFA et la course livreur 1 500 FCFA.    |
|       Votre marge brute unitaire est de 10 500 FCFA.                    |
|                                                                         |
| 2. VOTRE COÛT PAR PROSPECT ESTIMÉ À OUAGA (CPL)                         |
|    -> Ce que coûte en moyenne l'obtention d'un message WhatsApp d'achat.|
|    -> Sur le marché ouagalais, la moyenne se situe autour de 250 FCFA.  |
|                                                                         |
| 3. VOTRE TAUX DE CONVERSION COMMERCIAL (TC)                             |
|    -> Sur 10 personnes qui vous écrivent sur WhatsApp, combien achètent ?|
|    -> Pour une équipe commerciale moyenne à Ouaga : 10 % à 20 %         |
|       (soit 1 à 2 ventes fermes pour 10 prospects reçus).               |
|                                                                         |
+---

-+
```

### Le Coût d'Acquisition Client Maximal Tolérable (CAC Max)
Votre CAC Max est le montant plafond que vous pouvez vous permettre de dépenser en publicité pour acquérir un client sans perdre d'argent.
$$\text{CAC Max} = \text{Marge Brute Unitaire}$$

Si votre marge brute est de 10 500 FCFA, tant que vous dépensez moins de 10 500 FCFA en publicité pour obtenir une vente ferme, **votre campagne est rentable**. Si votre publicité vous coûte 2 500 FCFA par vente réalisée, vous empochez un bénéfice net pur de 8 000 FCFA par produit écoulé !
