## 2. Le Tutoriel Pas-à-Pas sur CapCut Mobile (100 % Gratuit)

L'application mobile **CapCut** (disponible gratuitement sur Android via Google Play Store et sur iOS) intègre l'un des meilleurs moteurs de reconnaissance vocale au monde pour la langue française.

Voici le protocole en 5 étapes pour sous-titrer votre vidéo d'entreprise :

```
[ÉTAPE 1] : IMPORTER LA VIDÉO DANS CAPCUT
* Ouvrez CapCut et cliquez sur "Nouveau projet".
* Sélectionnez votre vidéo tournée avec le smartphone.

[ÉTAPE 2] : LANCER LA GÉNÉRATION DES LÉGENDES AUTOMATIQUES
* Dans la barre d'outils inférieure, touchez l'icône "Texte" (symbole T).
* Choisissez "Légendes automatiques" (Auto Captions).
* Sélectionnez la source sonore "Son d'origine" et la langue "Français".
* Appuyez sur "Générer". En 30 secondes, l'intelligence artificielle 
  découpe votre discours en phrases parfaitement calées sur votre voix !

[ÉTAPE 3] : PERSONNALISER LE STYLE VISUEL POUR UNE LECTURE INSTANTANÉE
* Touchez l'un des blocs de sous-titres créés, puis appuyez sur "Style".
* Police recommandée : Choisissez une police grasse et compacte (ex. : The Bold Font).
* Couleur recommandée : Texte jaune vif ou blanc avec un contour noir épais.
  Le contraste doit être impeccable quel que soit l'arrière-plan de la vidéo.

[ÉTAPE 4] : L'EFFET DYNAMIQUE MOT PAR MOT (EFFET KARAOKÉ)
* Touchez l'onglet "Animation" dans le menu des sous-titres.
* Sélectionnez l'effet "Légende dynamique" : chaque mot s'allume en couleur 
  au moment exact où vous le prononcez. Cet effet hypnotise le regard !

[ÉTAPE 5] : RELECTURE RAPIDE DES NOMS PROPRES LOCAUX
* Balayez rapidement la vidéo pour vérifier les noms burkinabè.
* L'IA peut parfois confondre "Koudougou" ou "Ouaga 2000" avec un mot phonétique.
* Touchez simplement le mot pour corriger l'orthographe en 5 secondes.

## 3. Où Placer les Sous-Titres sur l'Écran ? La « Zone de Sécurité »

Une erreur fréquente commise par les débutants consiste à placer les sous-titres tout en bas de l'écran ou tout en haut.

Sur Facebook Reels et sur mobile, l'interface utilisateur de la plateforme vient recouvrir une partie importante de votre vidéo :
- **En bas à gauche :** Le nom de votre page, la description du post et la bande sonore masquent le bas de l'image.
- **À droite :** Les boutons « J'aime », « Commenter », « Partager » et « WhatsApp » occupent une bande verticale de 2 centimètres.
- **En haut :** La barre de recherche Facebook et l'encoche de la caméra frontale du téléphone mordent sur le haut de l'écran.

```
+---

-+
| [ZONE INTERDITE HAUTE : Évitée par sécurité]                |
|                                                             |
|                                                             |
|          +---

+          |
|          |     ZONE DE SÉCURITÉ OPTIMALE         |          |
|          |  Placez vos sous-titres ici,          |          |
|          |  juste au-dessous du niveau du torse  |          |
|          |  (À mi-chemin entre le centre et      |          |
|          |   le tiers inférieur de l'écran)      |          |
|          +---

+          |
|                                                             |
| [ZONE INTERDITE BASSE : Masquée par la description & icônes]|

En positionnant vos sous-titres dans cette **zone de sécurité centrale**, vous garantissez que 100 % de votre texte reste parfaitement lisible sur tous les modèles d'écrans de smartphones du marché sans être tronqué par les icônes de l'application Facebook.

## 4. Les 3 Règles d'Or Typographiques pour un Sous-Titrage Professionnel

1. **Pas plus de 4 à 6 mots par ligne :** Ne noyez pas l'écran sous un paragraphe géant. Les sous-titres modernes doivent apparaître par rafales courtes de 3 à 5 mots pour maintenir un rythme soutenu.
2. **Le contraste absolu :** N'écrivez jamais en texte noir sur un fond sombre ou en texte blanc pur sur une chemise blanche sans ombre portée. Utilisez toujours un contour sombre (Stroke) ou un fond rectangulaire noir semi-transparent derrière les lettres.
3. **Mettre en valeur les mots financiers clés :** Lorsque vous prononcez le prix (ex. : *« 35 000 FCFA »*) ou une garantie (ex. : *« Livraison Gratuite »*), changez la couleur de ce mot précis en jaune or ou en vert vif pour attirer l'œil instantanément.
