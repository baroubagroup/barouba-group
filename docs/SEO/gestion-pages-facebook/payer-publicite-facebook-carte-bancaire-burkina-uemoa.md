Pour résoudre un problème de paiement, il faut d'abord en comprendre les origines techniques et bancaires :

```
             LES 4 RAISONS PRINCIPALES DES REJETS BANCAIRES META
+---

-+
|                                                                         |
| 1. L'OPTION "PAIEMENT EN LIGNE INTERNATIONAL" DÉSACTIVÉE                |
|    -> Par défaut, de nombreuses banques burkinabè désactivent le        |
|       e-commerce international sur les cartes ordinaires pour limiter   |
|       les fraudes. Il faut expressément demander son activation.        |
|                                                                         |
| 2. LE DÉPASSEMENT DES PLAFONDS HEBDOMADAIRES OU MENSUELS                |

|       100 000 ou 200 000 FCFA par semaine. Dès que le seuil est atteint,|
|       le paiement Meta est rejeté net.                                  |
|                                                                         |
| 3. LE PROTOCOLE 3D SECURE (SMS OTP) INCOMPATIBLE AVEC META             |
|    -> Meta prélève les factures en tâche de fond de manière automatique |
|       sans pouvoir afficher la page de saisie du code SMS OTP de la     |
|       banque burkinabè. Si la carte exige un OTP à chaque débit,        |
|       la transaction échoue.                                            |
|                                                                         |
| 4. LE PROVISIONNEMENT INSUFFISANT DES FRAIS DE CHANGE                   |
|    -> Si vous devez 50 000 FCFA et que votre carte a exactement         |
|       50 000 FCFA, le prélèvement échoue car la banque ajoute 2 % à     |
|       3,5 % de frais de commission internationale.                      |
|                                                                         |

-+
```

```

+---

-+
| CHOIX N°1 : LE FRANC CFA D'AFRIQUE DE L'OUEST (XOF) - RECOMMANDÉ        |
```

## 5. Comment Obtenir des Factures Normalisées Déductibles Fiscalement au Burkina ?

Pour les entreprises assujetties au réel normal ou simplifié d'imposition à Ouagadougou, les dépenses publicitaires sur Facebook représentent des charges d'exploitation déductibles du bénéfice imposable (DGI / e-SINTAX).

### Les mentions légales obligatoires à renseigner dans Meta Ads :
1. Rendez-vous dans le Gestionnaire de Publicités > **Paramètres de paiement**.
2. Dans la section *"Informations sur l'entreprise"*, renseignez :
   - La raison sociale exacte : *Ex: FASO TRADING SARL*.
   - L'adresse géographique complète : *Ouagadougou, Secteur 15, Ouaga 2000, Burkina Faso*.
   - Votre numéro d'**Identifiant Fiscal Unique (IFU)** burkinabè.
3. Téléchargez mensuellement vos reçus officiels au format PDF dans la section *"Facturation"*. Ces factures émises par *Meta Platforms Ireland Ltd* sont recevables par l'administration fiscale burkinabè pour justifier les sorties de fonds professionnelles.

## Questions Fréquentes (FAQ)

### Peut-on payer la publicité Facebook avec Orange Money ?
Pas directement sur l'interface Meta. Vous devez lier une carte prépayée Visa/Mastercard (UBA, Coris) rechargeable par Mobile Money ou confier votre budget à une agence locale.

### Pourquoi Meta effectue-t-il un prélèvement de 1 dollar au début ?
C'est un test technique d'autorisation bancaire qui est annulé et remboursé automatiquement dès confirmation de la carte.

### Quel est le plafond initial de dépense sur un nouveau compte ?
Le plafond de démarrage se situe généralement entre 15 000 et 30 000 FCFA par jour, et s'élève progressivement avec l'historique positif de paiements.

### Quel est le forfait mensuel moyen recommandé pour une PME à Ouagadougou ?
Pour une PME cherchant une croissance réelle, les forfaits démarrent généralement à 150 000 FCFA HT/mois, incluant la conception graphique sur-mesure, des vidéos Reels dynamiques, la modération des commentaires et un reporting commercial mensuel.
