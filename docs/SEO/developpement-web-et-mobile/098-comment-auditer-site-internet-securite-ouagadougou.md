## 2. Pilier 1 : L'Audit de Vitesse et d'Ergonomie Mobile sur le Réseau Local

Au Burkina Faso, un site web qui ne s'ouvre pas immédiatement sur smartphone est un site mort :

### Le Test Pratique Immédiat :
1. Rendez-vous sur l'outil officiel gratuit de Google : **PageSpeed Insights** (`pagespeed.web.dev`).
2. Saisissez l'adresse de votre site et analysez impérativement l'onglet **« Mobile »** (et non Desktop).
3. Observez vos résultats :
   * **Score entre 0 et 49 (Zone Rouge) :** Votre site est en danger critique. Il perd plus de 65 % de ses visiteurs avant affichage.
   * **Score entre 50 et 89 (Zone Orange) :** Performance médiocre. Des goulets d'étranglement majeurs ralentissent la navigation.
   * **Score entre 90 et 100 (Zone Verte) :** Excellence technique digne des standards de BAROUBA GROUP.

### Ce Qu'il Faut Vérifier sur le Terrain à Ouaga :
- Les boutons d'action sont-ils facilement cliquables avec le pouce sans zoomer ?
- Les textes sont-ils lisibles sans avoir à faire défiler l'écran horizontalement ?
- Les photos de vos produits mettent-elles plus de 2 secondes à apparaître en connexion 4G ?

## 3. Pilier 2 : L'Audit de Cybersécurité et de Vulnérabilité

Un piratage peut ruiner la réputation de votre entreprise en une seule nuit :

```
             CHECKLIST CYBERSÉCURITÉ EN 5 POINTS RAPIDES :
+---

--+
| [ ] 1. Le cadenas HTTPS est-il vert et sans message d'erreur ?|
| [ ] 2. La page de connexion administrateur est-elle masquée ? |
|        (Tapez votresite.com/wp-admin : si la page s'affiche,  |
|        votre site est exposé aux attaques de robots !)       |
| [ ] 3. Les extensions et le CMS sont-ils mis à jour ?        |
| [ ] 4. Vos sauvegardes sont-elles externalisées hors-site ?   |
| [ ] 5. Vos formulaires sont-ils protégés par un anti-spam ?   |
+---

--+
```

### Le Diagnostic Malware Caché :
Tapez dans la barre de recherche Google : `site:votredomaine.com`.
Examinez les résultats affichés. Si vous apercevez des titres bizarres en anglais, en japonais, ou faisant la promotion de médicaments ou de jeux de casino, **votre site a été piraté par injection de code malveillant (SEO Spam)**, même si la page d'accueil semble normale à vos yeux.

## 4. Pilier 3 : L'Audit de Référencement Naturel Local (SEO Google.bf)

Votre site apparaît-il lorsqu'un client potentiel cherche vos services à Ouagadougou ?

### Le Test Incognito sur Google :
1. Ouvrez une fenêtre de navigation privée sur votre téléphone.
2. Tapez vos mots-clés d'activité sans mentionner le nom de votre entreprise :
   * Ex. *« clinique privée Ouagadougou »*, *« société gardiennage Burkina »*, *« avocat droit des affaires Ouaga »*, *« location véhicules 4x4 Bobo »*.
3. Observez où se classe votre entreprise :
   * **Dans le Top 3 (Première Page) :** Votre référencement est excellent.
   * **En 2e ou 3e page :** Votre site est virtuellement invisible (moins de 4 % des internautes dépassent la première page).
   * **Introuvable :** Votre prestataire a oublié de configurer le référencement de base.

## 5. Pilier 4 : L'Audit de Conversion et de Vente (La Clôture Commerciale)

Un site web n'a pas vocation à être une œuvre d'art muséale : son rôle est de remplir le carnet de commandes de vos commerciaux.

### Posez-vous Ces 4 Questions Cruciales :
1. **Le bouton WhatsApp fonctionne-t-il vraiment ?** En cliquant dessus, ouvre-t-il une discussion avec un message pré-rédigé vers le bon commercial, ou mène-t-il vers un numéro suspendu ou erroné ?
2. **Vos formulaires de devis sont-ils trop longs ?** Si vous demandez 10 informations obligatoires (dont l'adresse postale ou le fax !), vos clients abandonnent.
3. **Vos prix ou fourchettes tarifaires en FCFA sont-ils mentionnés ?** L'absence totale de tarif fait fuir le consommateur burkinabè qui craint de se faire surfacturer.
4. **Vos coordonnées physiques sont-elles claires ?** Votre adresse à Ouaga (quartier, rue, repères connus comme *« face à la station Total »*) dissipe la peur de l'escroquerie.
