## 2. La Révolution des Nouveaux Formats Graphiques : Exit le JPEG et le PNG !

Pendant trois décennies, le web a fonctionné avec deux formats historiques : le JPEG pour les photos et le PNG pour les logos avec transparence. En 2026, ces formats sont devenus obsolètes pour le web mobile.

```
       COMPARAISON DU POIDS D'UNE MÊME PHOTO EN HAUTE DÉFINITION :
+---

--+
| Format PNG Original       : [#################### 2 800 Ko #] |
| Format JPEG Standard      : [############ 1 100 Ko #]        |
| Format WebP Moderne (Google): [### 220 Ko #] (-80 % de data !) |
| Format AVIF Nouvelle Gén. : [## 140 Ko #] (-87 % de data !)  |
+---

--+
```

### Pourquoi le WebP et l'AVIF Écrasent Leurs Prédécesseurs :
- **Algorithmes de Prédiction Prédictive :** Ils analysent les blocs de pixels voisins pour ne coder que les variations réelles, offrant une netteté visuelle indiscernable de l'original à l'œil nu sur un écran de smartphone.
- **Gestion Supérieure de la Transparence :** Le WebP gère les fonds transparents en pesant 3 fois moins lourd qu'un PNG traditionnel.
- **Compatibilité Universelle :** Plus de 97 % des smartphones en circulation au Burkina Faso (Android et iOS récents) décodent nativement le WebP sans aucun ralentissement processeur.
