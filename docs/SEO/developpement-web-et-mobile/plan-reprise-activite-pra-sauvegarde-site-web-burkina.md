## 1. Comprendre les Deux Indicateurs Vitaux : RTO et RPO à Ouagadougou

Tout Plan de Reprise d'Activité digne de ce nom repose sur deux notions fondamentales que tout Directeur Général et Directeur Administratif et Financier (DAF) burkinabè doit maîtriser :

```
             LES 2 BOUSSOLES DE LA CONTINUITÉ D'ACTIVITÉ :
+---

--+
| 1. RTO (Recovery Time Objective) - Durée Maximale d'Arrêt    |
|    ➔ "Combien de temps pouvons-nous rester hors-ligne ?"    |
|    Exemple BAROUBA GROUP : MOINS DE 2 HEURES pour redémarrer. |
|                                                              |
| 2. RPO (Recovery Point Objective) - Perte Maximale de Données|
|    ➔ "Jusqu'à quel moment dans le passé perdons-nous ?"      |
|    Exemple BAROUBA GROUP : MOINS DE 6 HEURES d'opérations.   |
+---

--+
```

### Le RTO (Recovery Time Objective)
C'est le temps chrono nécessaire pour remettre votre site web et vos outils de commande en ligne après un crash majeur. Si votre RTO est de 5 jours, vous perdez 5 jours complets de chiffre d'affaires, de commandes et de crédibilité commerciale auprès de vos partenaires.

### Le RPO (Recovery Point Objective)
C'est l'âge de la sauvegarde la plus récente que vous restaurez. Si vous n'avez fait une sauvegarde que dimanche dernier et que le crash survient le vendredi à 16h, vous avez définitivement perdu toutes les ventes, les factures et les contacts enregistrés du lundi au vendredi.

## Questions Fréquentes (FAQ)

### Qu'est-ce qu'un test de simulation de sinistre (Disaster Recovery Test) ?
Il s'agit d'un exercice pratique mesurant la capacité réelle de l'infrastructure à ressusciter l'ensemble des données et applications dans le respect des délais contractuels.

### Les sauvegardes cloud consomment-elles la bande passante internet de notre bureau à Ouaga ?
Non, les flux de sauvegarde s'opèrent de machine à machine dans les datacenters sans aucun impact sur la connexion Wi-Fi de vos bureaux.

### Est-ce que ce système protège également nos boîtes emails professionnelles ?
Absolument, nos solutions répliquent simultanément la base applicative, les fichiers et l'ensemble de l'historique de vos courriels professionnels.

### Quel est le délai moyen de livraison d'un projet web ou mobile par BAROUBA GROUP à Ouaga ?
Le calendrier type s'étend de 2 à 3 semaines pour un site vitrine professionnel haute performance, et de 4 à 8 semaines pour une plateforme e-commerce avancée ou une application mobile Flutter sur-mesure.

### Comment assurez-vous la compatibilité avec les connexions Internet lentes au Burkina ?
Nous concevons nos architectures avec Next.js et des technologies de rendu statique optimisées, complétées par la mise en cache locale (Service Workers). Les pages s'affichent instantanément même sur les réseaux mobiles 3G instables.

### Comment s'effectue l'intégration des passerelles Orange Money, Wave et Moov Money ?
BAROUBA GROUP connecte directement les APIs officielles sécurisées des opérateurs télécoms et agrégateurs régionaux avec gestion des webhooks d'encaissement et confirmation instantanée par SMS aux clients.
