## 1. Les 3 Erreurs UX Qui Font Échouer les Livraisons à Ouagadougou

### Erreur #1 : Rendre le Champ « Code Postal » Obligatoire
Au Burkina Faso, le code postal universel n'est pas utilisé par la population pour les livraisons quotidiennes. Bloquer la validation d'une commande parce que le client n'a pas tapé un code postal imaginaire (comme 00226 ou BP 01) provoque l'abandon immédiat de 30 % des acheteurs.

### Erreur #2 : Demander Trop de Champs de Texte Inutiles
Sur un smartphone connecté à la 4G, taper des pavés de texte décourage l'internaute. Chaque champ superflu (Nom de société, Adresse ligne 2, Région, Pays) réduit votre taux de conversion d'au moins 15 %.

### Erreur #3 : L'Absence de Repères Urbains Clairs
Le client burkinabè s'oriente par rapport à des monuments connus : une station-service (TotalEnergies, Shell, Petrofa), une pharmacie, une école ou une mosquée. Ne pas lui laisser d'espace pour indiquer ce point de repère garantit que le coursier appellera 5 fois pour demander son chemin.

## 3. Les Deux Technologies Gagnantes de Géolocalisation à Ouaga

Pour aller plus loin que les simples descriptions verbales, deux technologies permettent d'automatiser le guidage des coursiers :

### A. Le Partage de Position Direct via WhatsApp (La Solution Reine)
Puisque chaque coursier à moto dispose d'un smartphone Android avec l'application WhatsApp et Google Maps :
1. Dès que la commande est enregistrée sur votre site, le serveur envoie un message automatique au client : *« Merci Moussa pour votre commande ! Cliquez ici pour envoyer votre position GPS WhatsApp à notre coursier pour un acheminement direct »*.
2. Le client clique sur la trombone WhatsApp, sélectionne *« Partager ma localisation »*.
3. Le coursier clique sur le point GPS reçu et l'application Google Maps lance immédiatement le guidage vocal virage par virage jusqu'au portail exact de la maison !

### B. L'Intégration des Google Plus Codes (Open Location Code)
Google a développé un système d'adressage mondial gratuit pour les pays sans noms de rues : les **Plus Codes**.  
Une adresse à Ouagadougou devient par exemple : `8F2J+3C Ouagadougou`.  
Sur notre formulaire e-commerce, un bouton *« Me localiser »* utilise le GPS du smartphone du client pour générer automatiquement son code Plus Code sans qu'il ait besoin de le calculer.

## Questions Fréquentes (FAQ)

### Comment livrer un colis à Ouagadougou sans nom de rue précis ?
Le formulaire e-commerce permet de sélectionner le quartier de Ouaga dans une liste, d'indiquer un repère urbain connu (pharmacie, station, rond-point) et d'envoyer sa position GPS directement sur WhatsApp au coursier d'un simple clic.

### Faut-il mettre un code postal sur un site e-commerce burkinabè ?
Non. Le code postal n'est pas utilisé pour la distribution de colis au Burkina Faso. Le rendre obligatoire fait chuter le taux de conversion de la boutique en ligne. Il doit être supprimé ou rendu facultatif.
